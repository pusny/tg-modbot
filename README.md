# TG Moderation Bot

Модератор-бот для Telegram-чатов на `python-telegram-bot`.

## Возможности

- ранги: owner, senior_admin, junior_admin, senior_mod, junior_mod, user
- команды модерации: ban, unban, kick, mute, unmute, warn, unwarn, warns
- инлайн-меню `/mod` с кнопками под сообщением
- триггер-слова с автонаказанием (warn / mute / kick / ban)
- кружки (группы) внутри чата или топика
- антиспам: флуд → авто-мут
- антирейд: всплеск вступлений → алерт в админ-чат
- чистка сообщений в конкретной теме или во всём чате
- запрет ссылок в конкретной теме или во всём чате
- репорты: из чата → в админ-топик с инлайн-кнопками
- профиль участника: `/profile` и `/me`
- кто добавил бота в чат — автоматически становится owner

## Установка

### 1. Клонируй репозиторий

```
git clone https://github.com/твой_логин/tg-modbot.git
cd tg-modbot
```

### 2. Создай .env

В папке проекта создай файл `.env` со строкой:

```
BOT_TOKEN=123456:AAA-твой_токен
```

Токен получается у [@BotFather](https://t.me/BotFather).

### 3. Установи зависимости

```
pip install -r requirements.txt
```

### 4. Настрой параметры в bot.py

В начале `bot.py` есть блок с настройками:

```python
ADMIN_CHAT_ID    = -1004441293896
REPORT_THREAD_ID = 1538
```

- `ADMIN_CHAT_ID` — id чата, куда летят репорты и алерты
- `REPORT_THREAD_ID` — id топика внутри этого чата (0 = без топика)

Чтобы узнать id чата, добавь бота в чат и перешли любое сообщение боту [@userinfobot](https://t.me/userinfobot) или [@getidsbot](https://t.me/getidsbot).

### 5. Запусти

```
python bot.py
```

## Деплой на Bothost

1. Залей репозиторий на GitHub
2. Открой [bothost.ru/create-bot.php](https://bothost.ru/create-bot.php)
3. Заполни форму:
   - платформа: Telegram
   - библиотека: Python
   - bot token: вставь токен
   - git url: ссылка на репозиторий
4. Главный файл (точка входа): `bot.py`
5. В переменных окружения проверь `BOT_TOKEN`
6. Нажми «Создать» и дождись сборки

## Настройка бота в чате

1. Добавь бота в целевой чат
2. Тот, кто добавил — автоматически получает ранг `owner`
3. Дай боту админку со следующими правами:
   - удаление сообщений
   - блокировка участников
   - ограничение участников
   - управление темами (для форумов)
   - закрепление сообщений

## Команды

### Ранги

| Команда | Минимальный ранг | Описание |
|---|---|---|
| `/setrank <alias>` | owner | выдать ранг реплаем |
| `/ranks` | все | список алиасов |

### Модерация

| Команда | Минимальный ранг | Описание |
|---|---|---|
| `/mod` | junior_mod | меню с инлайн-кнопками |
| `/ban [причина]` | junior_admin | забанить |
| `/unban <user_id>` | junior_admin | разбанить |
| `/kick` | junior_mod | кикнуть |
| `/mute 10m` | junior_mod | замутить |
| `/unmute` | junior_mod | размутить |
| `/warn` | junior_mod | предупреждение |
| `/unwarn` | junior_mod | сбросить варны |
| `/warns` | junior_mod | посмотреть варны |

### Триггеры

```
/trigger add <слово> [warn|mute|kick|ban]
/trigger del <слово>
/trigger list
```

### Кружки

```
/create_circle <название>
/join <название>
/leave <название>
/circle_info <название>
/delete_circle <название>
```

### Темы и чат

```
/clean <N>       — удалить N последних сообщений
/links on|off    — включить/выключить ссылки
```

### Прочее

```
/report [причина]  — реплай → жалоба в админ-чат
/profile           — профиль участника
/me                — свой профиль
/settings          — настройки антиспама и антирейда
/help              — список команд
```

## Алиасы рангов

- `owner` — создатель
- `senior_admin` — старший администратор
- `junior_admin` — младший администратор
- `senior_mod` — старший модератор
- `junior_mod` — младший модератор
- `user` — участник

## Длительности мута

Формат: `число + единица`

- `30s` — 30 секунд
- `10m` — 10 минут
- `2h` — 2 часа
- `1d` — 1 день

## Требования

- Python 3.10+
- права администратора у бота в целевом чате
