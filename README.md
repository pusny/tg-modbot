🤖 Camelot Mod — Telegram-бот модерации

Многофункциональный бот-модератор для Telegram-групп: антиспам, антирейд, триггеры, варны/муты/баны, кружки, репорты и голосовая расшифровка. Работает на длинном поллинге, хранит состояние в SQLite, активируется в каждом чате по ключу.

---

📋 Возможности

Модерация

· Варны — предупреждения с TTL (сгорают по времени), лимит настраивается.
· Муты — временные и вечные, авто-размут по истечении срока.
· Кик / Бан — с указанием срока и причины, авто-разбан для временных банов.
· Авто-действия при N варнах — мут / бан / кик (настраивается).
· Сброс варнов вручную и авто-сброс по истечении TTL.
· Меню мод — inline-клавиатура для быстрых действий в один клик.

Защита чата

· Антиспам — счётчик флуда за окно, авто-мут при превышении.
· Антирейд — детект массовых входов, алерт админам.
· Триггеры — авто-реакция на запрещённые слова (варн/мут/кик/бан).
· Защита от ссылок — настраиваемое действие: удаление / варн / мут / кик / бан. Отдельные правила по темам (topics).
· Служебные чаты (ADMIN_CHAT_ID, REPORT_CHAT_ID) игнорируются фильтрами.

Сообщество

· Кружки — создание/удаление, вступление/выход, инфо, участники.
· Профиль — ранг, варны, муты, кружки пользователя.
· Репорты — жалобы от участников с кнопками модерации.

Администрирование

· Система рангов — 6 уровней (Создатель → Участник) с иерархией прав.
· Кастомные теги участников через set_chat_member_tag.
· Активация по ключу — чат работает только после ввода ключа.
· Авто-снятие ранга при выходе/бане из чата.
· Подробные настройки через команду настройки.

Голос

· Расшифровка голосовых и видеокружков через Vosk (офлайн, русская модель).
· Авто-выгрузка модели из RAM при простое (180 сек).

Надёжность

· Watchdog — перезапуск при падении поллинга.
· WAL-режим SQLite + периодический checkpoint и ротация бэкапов.
· Семафоры на Telegram API и БД (защита от rate-limit и lock).
· Retry-логика на сетевых ошибках и RetryAfter.
· Авто-рестарт процесса при фатальном сбое.

🚀 Установка

1. Требования

· Python 3.10+
· ffmpeg (или используется встроенный из imageio-ffmpeg)
· ~2 ГБ диска под Vosk-модель (скачивается автоматически)
· Токен бота от @BotFather

2. Клонирование и запуск

```bash
git clone <repo> camelot-mod
cd camelot-mod
pip install python-telegram-bot>=22,<24 python-dotenv vosk numpy imageio-ffmpeg
python bot.py
```

Скрипт сам установит недостающие зависимости через _ensure() при первом запуске.

3. Docker (пример)

```dockerfile
FROM python:3.12-slim
RUN apt-get update && apt-get install -y --no-install-recommends ffmpeg && rm -rf /var/lib/apt/lists/*
WORKDIR /app
COPY bot.py .
VOLUME ["/app/data"]
CMD ["python", "bot.py"]
```

Создай .env рядом со скриптом:

```dotenv
# Обязательные
```

REPORT_THREAD_ID ❌ 0 ID треда в чате репортов

VOSK_MODEL_DIR ❌ /app/data/vosk Директория для модели Vosk

🔑 Активация бота в чате

Бот не работает в чате до активации.

1. Добавь бота в группу (права: удаление сообщений, бан, ограничение участников).
2. Администратор чата пишет активация или /activate.
3. Бот присылает в лог ключ вида ABCD1234XYZ9.
4. Написать в чат: активация ABCD1234XYZ9.
5. Готово — бот активен, активировавший становится Создателем.

Служебные чаты (ADMIN_CHAT_ID, REPORT_CHAT_ID) активации не требуют.

👑 Ранги

Уровень Название Тег
100 👑 Создатель Создатель
80 🛡 Старший администратор Ст. Админ
60 🛡 Младший администратор Мл. Админ
40 ⚔ Старший модератор Ст. Модератор
20 ⚔ Младший модератор Мл. Модератор
0 👤 Участник —

Алиасы для выдачи ранга: owner, senior_admin, junior_admin, senior_mod, junior_mod, user и русские эквиваленты (владелец, ст_админ, мл_мод и т.д.). Полный список — в RANK_ALIASES или через команду ранги.

Правила:

· Создатель чата в Telegram автоматически получает RANK_OWNER.
· Администраторы Telegram — минимум RANK_SENIOR_ADMIN.
· Нельзя выдать/снять ранг ≥ своего.
· Ранг автоматически снимается при выходе/бане.

SQLite, WAL-режим. Файл: ${DATA_DIR}/bot.db или ${DB_PATH}.

🛠️ Технические детали

Константы (в коде)

```python
TG_SEND_SEMAPHORE = 20      # одновременных отправок в Telegram
DB_READ_SEMAPHORE = 3       # одновременных чтений БД
DB_EXECUTORS = 4            # потоков для записи в БД
WATCHDOG_INTERVAL = 60      # сек между проверками поллинга
WATCHDOG_MAX_FAILS = 5      # фейлов getMe до рестарта
ASR_IDLE_UNLOAD_SEC = 180   # сек простоя до выгрузки Vosk
HOUSEKEEPING_INTERVAL = 300 # сек между циклами housekeeping
MESSAGES_RETENTION_SEC = 86400  # хранить сообщения сутки
STALE_UPDATE_SEC = 300      # игнорировать апдейты старше 5 минут
```

Middleware (порядок обработки)

1. activation_mw (group −300) — блокирует неактивные чаты
2. stale_mw (−250) — отсекает устаревшие апдейты
3. private_block_mw (−100) — отвечает отказом в личке
4. pre_remember (−4) — сохраняет сообщения в БД
5. antispam_mw (−3) — антифлуд
6. link_guard_mw (−2) — проверка ссылок
7. trigger_mw (−1) — триггерные слова
8. _handle_voice / _handle_video_note (−1) — расшифровка
9. Обычные хендлеры команд и русских алиасов

Логирование

· Уровень: INFO (debug — по необходимости).
· Сетевые шумы httpx / httpcore приглушены.
· Логи действий идут в ADMIN_CHAT_ID.
· Репорты — в REPORT_CHAT_ID.

🩺 Диагностика

Бот не работает в чате:

· Проверь, активирован ли чат (activations).
· Убедись, что у бота права админа.
· Проверь, что в логах нет Conflict (другой инстанс).

Голосовые не расшифровываются:

· В логах должно быть ffmpeg → /path/to/ffmpeg.
· Проверь наличие VOSK_MODEL_DIR и прав на запись.
· Модель скачивается автоматически (~1.8 ГБ), первый запуск может занять время.

«БД заблокирована»:

· WAL-режим уже включён, но проверь, что папка БД на локальном диске (не NFS/сетевой шэре).
· В логах _sync_exec ретраит 4 раза по 150/300/450 мс.

Потеря состояния между пересборками:

· Лог ⚠️ Маркер персистентности отсутствует означает, что volume не сохраняется.
· Смонтируй DATA_DIR как Docker volume.
